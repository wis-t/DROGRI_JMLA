# متجر متجري+

متجر إلكتروني ثابت (HTML/CSS/JavaScript) جاهز للنشر على **GitHub Pages** و **Vercel**.

## الملفات
- `index.html` — واجهة المتجر.
- `cart.html` — سلة المشتريات.
- `admin.html` — لوحة إضافة وحذف المنتجات.
- `style.css` — التصميم والألوان.
- `app.js` — المنتجات والسلة والبحث.
- `vercel.json` — إعدادات Vercel والروابط `/`, `/cart`, `/admin`.

## النشر على Vercel
1. ارفع **كل الملفات الموجودة داخل هذا المجلد** إلى Repository على GitHub.
2. في Vercel اختر **Add New → Project**.
3. اختر الـ Repository.
4. لا تحتاج إلى Build Command أو Framework.
5. اضغط **Deploy**.

بعد النشر:
- المتجر: `/`
- السلة: `/cart`
- الإدارة: `/admin`

إذا ظهر إصدار قديم، اعمل Redeploy مع تعطيل استخدام Cache، ثم افتح الموقع في نافذة خاصة.

## النشر على GitHub Pages
من إعدادات Repository اختر Pages → Deploy from branch → `main` → `/ (root)`.

## مهم بخصوص لوحة الإدارة
هذه النسخة تستخدم `localStorage`، لذلك المنتجات التي تضيفها من لوحة الإدارة تُحفظ في **نفس المتصفح والجهاز فقط**. هذا مناسب للتجربة والنسخة الأولية، لكنه ليس نظام إدارة حقيقيًا متعدد الأجهزة.

لتحويله إلى متجر حقيقي، يمكن لاحقًا ربط لوحة الإدارة بقاعدة بيانات وتسجيل دخول وصور وطلبات.
